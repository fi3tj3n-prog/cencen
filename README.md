# Cencen

Aplikasi pencatat keuangan harian: total saldo, pemasukan/pengeluaran bulanan, saldo per dompet (Tunai, Bank Mandiri, Bank Jatim, E-wallet), scan struk, impor mutasi, rencana anggaran per kategori, dan analisa.

Cukup buka `index.html` di browser. Data tersimpan di perangkat (localStorage).

Bisa dipasang gratis lewat GitHub Pages: Settings → Pages → Branch `main` / root.
